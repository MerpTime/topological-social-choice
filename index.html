Averaging Angles

Each voter’s preference is now a point on the circle \(S^1\). A social choice rule takes everyone’s points and returns a single point for the group. With two voters, that is a function \(\varphi : S^1 \times S^1 \to S^1\). There are three properties that are essential for a fair voting system:

Unanimity

If everyone agrees, the group chooses what they agree on.

\(\varphi(x, x) = x\)

Anonymity

It doesn’t matter who cast which vote.

\(\varphi(x, y) = \varphi(y, x)\)

Continuity

A small change in anyone’s vote causes only a small change in the outcome.

\(\varphi\) is continuous

An intuitive voting system is to average the two angles:

Winding Numbers

A loop in \(S^1\) is a path around the circle that ends where it started. Its winding number counts how many times it goes around: each counterclockwise turn counts \(+1\), and each clockwise turn counts \(-1\).

The same path, unwound

Turns so far 0.00

Follow the angle of the point as it moves, without ever resetting it to \(0^\circ\) when it passes \(360^\circ\). Call this running angle \(\theta(t)\), where \(t\) goes from \(0\) at the start of the loop to \(1\) at the end, and \(\theta(0) = 0^\circ\). This is the helix on the right: going around the circle once lifts you one level up the helix.

On a closed loop, the point is back where it started, so \(\theta(1)\) and \(\theta(0)\) describe the same point on the circle. Two angles describe the same point exactly when they differ by a whole number of full turns, so \[ \theta(1) - \theta(0) = 2\pi n \quad \text{for some } n \in \mathbb{Z}. \] That integer \(n\) is the winding number. Because \(n\) is an integer, it can’t change gradually. Deforming a loop continuously would have to change its winding number continuously, and the only way for a whole number to change continuously is not to change at all.

Loops on the torus

A point on \(S^1 \times S^1\) is a pair of angles \((\theta_1, \theta_2)\), which can be visualized as a torus. Moving \(\theta_1\) carries you around the long way, and moving \(\theta_2\) carries you around the tube.

A loop on the torus therefore has two winding numbers, \((m, n)\): \(m\) counts how many times \(\theta_1\) goes around its circle, and \(n\) counts how many times \(\theta_2\) does.

Suppose there is a rule \(\varphi\) that is unanimous, anonymous and continuous. Here is the picture we’ll use to show that it can’t exist.

Three loops of votes. Along \(\alpha\), voter 1’s vote goes around once while voter 2’s stays put. Along \(\beta\), voter 2’s goes around while voter 1’s stays put. Along \(\delta\), both go around together, always agreeing.

Since \(\varphi\) is continuous, it turns each loop of votes into a loop on the output circle, and each of those has a winding number. Call them \(m\) for \(\alpha\) and \(n\) for \(\beta\).

Anonymity says \(\varphi(\theta, 0) = \varphi(0, \theta)\). Swapping the two voters turns \(\alpha\) into \(\beta\) without changing the outcome, so the two output loops are identical, and \(m = n\).

Unanimity says \(\varphi(\theta, \theta) = \theta\). Along \(\delta\) the voters always agree, so the output just goes around the circle once: \(\varphi(\delta)\) has winding number \(1\).

On the square, \(\delta\) slides smoothly into \(\alpha\) followed by \(\beta\) (the right edge is glued to the left edge, so it is \(\beta\)). Because \(\varphi\) is continuous, the output loop slides smoothly too, so its winding number can’t change. Going around \(m\) times and then \(n\) times gives \(m + n\), so \(m + n = 1\).

Together, \(m = n\) and \(m + n = 1\) give \(2m = 1\), so \(m = \tfrac{1}{2}\). But \(m\) is a winding number, and winding numbers are integers. No rule can be unanimous, anonymous and continuous.
